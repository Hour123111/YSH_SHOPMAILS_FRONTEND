Check Balance

Method: GET

Endpoint: /v1/api/user

Headers:

  • api_key: your API key

Example Request (Python):

import requests

url = "https://yshshopmails.com/v1/api/user"
headers = {
    "api_key": "your_api_key_here"
}

response = requests.get(url, headers=headers)
data = response.json()
print("Balance:", data)

Response (JSON):

{
  "balance": "19.196",
  "id": "5P5HSlavoESjx3dwasd"
}

Check Stock And Price

Method: GET

Endpoint: /v1/stock

Parameters:

  • service: service name (e.g. facebook, outlooktrust, outlooknew, hotmailtrust, hotmailnew, novery_kh, novery_us)

Example Request (Python):

import requests

url = "https://yshshopmails.com/v1/stock"
params = {
    "service": "facebook"
}

response = requests.get(url, params=params)
data = response.json()
print(data)

Response (JSON):

{
  "price": x.xx,
  "status": "success",
  "stock": 0
}

Create OTP Order

Method: GET

Endpoint: /v1/api/create-order.php

Parameters:

  • key: your API key
  • service: service name: facebook

Example Request:

https://yshshopmails.com/v1/api/create-order.php?key={{ .Token }}&service=facebook

Response (JSON):

{
  "mail": "example@gmail.com",
  "order_id": "abc123xyz"
}

Get OTP

Method: GET

Endpoint: /v1/api/check-otp.php

Parameters:

  • key: your API key
  • id: the order_id from the create step

Example Request:

https://yshshopmails.com/v1/api/check-otp.php?key={{ .Token }}&id=abc123xyz

Response (JSON):

{
  "otp": "123456",
  "amount": "0.042",
  "time": "2025-09-14 23:49:55"
}
